Ты завершаешь рабочую сессию по проекту **TIM**. Задача — не потерять ни одного изменения.

## Шаг 1 — Синхронизировать ROADMAP

Перед коммитом приведи @ROADMAP.md в соответствие с тем, что реально сделано:

- отметь выполненные пункты `[x]`, незавершённые — `[~]`;
- закрой строки в «Журнале задач» (статус «Готово» / «В работе» / «Отложено»);
- обнови раздел «Блокеры», если что-то снялось или появилось;
- если по ходу сессии менялись решения — внеси их в «Журнал решений»;
- обнови поля **Обновлён** и **Текущий этап** в шапке файла.

Не приписывай сделанным то, что не сделано. Если пункт закрыт частично — так и пометь.

## Шаг 2 — Проверить, что коммитим

```
git status
git diff --stat
```

Убедись, что в индекс не попадают: `.env*` (кроме `.env.example`), `node_modules/`, `.next/`, ключи, токены, персональные данные.
Если в изменениях есть секрет — **не коммить**, останови процесс и скажи об этом заказчику.

## Шаг 3 — Коммит

```
git add -A
```

Сообщение коммита — на русском, по существу: что сделано и какие пункты ROADMAP закрыты.
Формат:

```
<краткая суть в одну строку>

- <изменение 1>
- <изменение 2>

ROADMAP: закрыты пункты X.Y, X.Z

Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
```

Если изменений нет — не создавай пустой коммит, просто сообщи об этом.

## Шаг 4 — Push

Проверь наличие remote: `git remote -v`.

- **Remote есть** → `git push`. Если ветка новая — `git push -u origin <branch>`.
- **Remote нет** → не пытайся его создавать и не выдумывай URL. Сообщи: «Remote не подключён, изменения закоммичены локально», и напомни команду:
  `git remote add origin <url> && git push -u origin main`
- **Push упал** (нет доступа, отклонён) → покажи реальный вывод ошибки. Не делай `--force`.

## Шаг 5 — Итог сессии

Короткая сводка на русском:

- что сделано за сессию;
- хеш коммита и статус push (выполнен / пропущен / упал — и почему);
- что следующее по ROADMAP;
- какие блокеры ждут заказчика.

Отчитывайся честно: если что-то не доделано или push не прошёл — скажи прямо.

Аргументы команды (например, уточнение к сообщению коммита): $ARGUMENTS
